# 視覺規範

預設走 MONO——單色、編輯風格。單色不只是美感選擇，它讓簡報不依賴顏色傳達資訊，因此在色盲、灰階列印、深色模式下都一致可讀。

已設定品牌 design system 時，讀取其 tokens 覆蓋以下數值；顏色若被覆蓋，仍維持「不用顏色編碼資料」的原則。

## Tokens

```
INK    #1C1C1A   主文字、標題、強調
PAPER  #F0EFEB   頁面底
CARD   #FBFAF7   卡片底
MUTED  #8F8E88   次要文字
FAINT  #C6C5BF   來源行、極次要
GRID   #DEDDD6   分隔線

灰階七階  #1C1C1A #4A4944 #6A6963 #8F8E88 #B0AFA9 #C6C5BF #D8D7D1
深色模式  上述反轉，底色 #141412，卡片 #1C1C1A
```

字體 Inter ＋ Noto Sans TC。

```
標題      19px / 700 / -0.02em
內文標題  15.5px / 700 / -0.015em

```

卡片圓角 24px，內距 32px。長條圓角 99px（膠囊）。

## 幾條規則

**數值用 800 weight。** 這是 MONO 的核心手法——在沒有顏色的系統裡，字重就是強調的主要手段。

**量級用長度編碼，不用顏色。** 逾期天數、進度、佔比一律畫成單色長條，深淺只用來分層不用來分類。這樣「嚴重」是靠長度看出來的，不是靠紅色。

**來源行是第一等公民。** 每一個結論都要能追回它從哪來。用 9.5px 大寫加字距寫在結論下方——小到不干擾閱讀，但存在感足以讓人知道這不是憑空生成的。

**分隔線只用 1px 實線。** 不要虛線、不要陰影分隔。段落之間靠留白，不靠框線。

**留白比塞滿重要。** 這份東西的競爭對手是使用者的收件匣，不是儀表板。看起來很滿就會被延後閱讀。
