# daily-brief — 個人化每日工作簡報

每個工作日產出一份 90 秒讀完的簡報：今天最該處理的一件事、行程、逾期任務、
以及**跨來源的連結**——一封信解鎖了哪幾張卡住的票、某家公司同時出現在
會議記錄和外部資料裡。判準只有一個：**它要告訴你至少一件你不知道、但該知道的事。**

核心紀律：每個數字都能點回去（來源標註＋回溯連結＋原始資料入口三件都要有）、
比率要寫算式、找不到就說找不到。

## 安裝（Claude Code）

```bash
cp -r daily-brief ~/.claude/skills/
```

然後說：**「daily brief」**或「幫我看一下今天」。第一次會走設定流程（見 `references/setup.md`）。

## 組織適配（重要）

**需要改成你們公司的檔案有兩份**：

- `references/sources.md` — 來源登錄表（任務系統、會議記錄、分析工具、廣告平台的實際位置）。
  **這份是簡報可信度的地基**：沒有它、簡報就是一個要求讀者相信它的黑箱。
- `references/brands.md` — 品牌 design system 對照（沒有就用內附的中性預設）。

其他檔案（模組庫、排版規格、說人話規則、設定流程）通用、不用動。

## 搭配

跟 [`interview-me`](../interview-me/) skill 是一對：訪談的第①站會當場產出你的第一份簡報骨架版、
訂閱後由這個 skill 接手每天產出。單獨用也完全可以。
