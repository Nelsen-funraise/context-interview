# interview-me — 脈絡與工作盤點訪談

由 AI 主持的結構化訪談。它先自己查、查不到才問你，每一題都附上它的猜測——你只要點頭或改。

- **第 60 秒就有第一張圖**（脈絡訊號圖 v0，哪怕上面還有問號）
- **一份會長大的記錄頁**：從第 60 秒開到收尾，人看得懂、下一個 AI 也讀得懂（`references/interview-record.md`）
- 第①站就拿到你自己的第一份每日簡報（真的產出來，不是設定檔）
- 三張圖都真的渲染成頁面：你的資料在哪、哪件事值得交出去、哪裡斷掉
- **交圖時它會先用白話把圖講回給你聽**，再問一個是非題——你糾正它的那句話，就是最有價值的輸入

**兩種長度**：完整版 30 分（五站走完）、快閃版 10 分（只問關鍵題，一樣交一份記錄頁）。
**三種模式**：自訪（預設）、協助訪談（你在現場問、AI 供題）、累積模式（每次三題、長期累積）。

## 安裝（Claude Code）

```bash
cp -r interview-me ~/.claude/skills/        # 個人層
# 或 cp -r interview-me your-project/.claude/skills/   # 專案層
```

然後說：**「interview me」** 或 **「訪談我」**。想接續上次的說「繼續上次的訪談」。

## 安裝（Claude.ai 網頁版）

開一個新對話（建議開成 Project）、把 `SKILL.md` 全文貼進去，說「照這份流程訪談我」。
網頁版查不到你本機的東西，地圖那一段會多用幾題問你。

**網頁版不會在你電腦上留檔**——記錄頁會做成一個 artifact，整場訪談都更新同一份。訪談結束把它下載下來，下次說「繼續上次的訪談」時貼回去就能接著談。

## 三種對象、三份情境檔（`profiles/`）

同一套方法、對象不同，預設值就不同。訪談開始前會先讀對應的那一份：

| 情境檔 | 給誰 | 差別 |
|---|---|---|
| `internal.md` | 公司同事、有組織的資料入口 | 查得到公司系統、找「可以交給 AI 接手的工作」、30 分鐘 |
| `solo.md` | 自己一個人、沒有公司資料入口 | 不掃描直接問、找「時間被吃掉的地方」、10 分鐘、東西存本機 |
| `course.md` | 課程學員 | 找「寫作卡在哪」、產出是助手的口氣設定（待課綱定案） |

判斷不了它會直接問你一題。

## 組織適配（給要導入自己公司的人）

整個 skill 只有一份檔要改成你們的：`references/organization-context.md`——名冊在哪、用什麼查人、你們自家資料的入口是什麼、每個部門的工作痕跡在哪。其他檔案是訪談方法本身、跨組織通用。

沒填也能跑，訪談會自動走 `profiles/solo.md`（全部用問的）。

## 紅線

- 薪資、考核、對特定同事的評價：不問、被動聽到也不記錄
- 你不想回答的問題：跳過、不追問第二次
- 存到哪、誰看得到：開場就講，不是事後才說
- 每份產出先給你過目、你點頭才算數
