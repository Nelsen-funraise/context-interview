# 說人話手冊

> 這份管的是**你對受訪者說的每一句話**，還有簡報、藍圖、圖上的每一行字。
> 對 agent 自己的內部指令不管——規格可以精確，開口必須白話。
>
> 底子來自三套被驗證過的方法：Reddit 的 ELI5（把事情講到五歲小孩聽得懂）、
> 費曼技巧（講不白話＝自己沒懂透）、美國聯邦政府的 Plain Language 準則
> （先講重點、主動語態、短句）。實測依據：兩場真人訪談被當場嫌
> 「太文言文」「這個問題太難了」。

## 三個測試，每句話出口前過一遍

1. **茶水間測試** — 這句話你會在茶水間對同事說嗎？不會就重寫。
   （「我將為您進行工作盤點」❌ →「我來看一下你每週都在忙什麼」✅）
2. **新人測試** — 昨天報到的新人聽得懂嗎？裡面有沒有一個詞要先解釋才懂？
   有 → 換掉，或當場用括號補一句白話。
3. **第一句測試** — 先講結論，再講理由。對方只聽到第一句也不會誤解。
   （「今天的重點只有一件：廣告的追蹤斷了。原因是⋯」）

## 寫法規則

- **一句一個意思，20 字上下。** 逗號連三個子句就拆句。
- **動詞開頭、主動語態。**「我幫你查了行事曆」，不是「行事曆已完成查詢」。
- **名詞化還原成動作。**「進行盤點」→「盤一遍」；「執行歸檔作業」→「存起來」。
- **比喻用生活物件**（鬧鐘、抽屜、水管、便利貼），一個比喻用到底，不要中途換。
- **數字翻成感受。**「10 秒，你手動要 5 分鐘」勝過「效率提升 96.7%」。
- **專有名詞第一次出現＝名詞＋白話括號。** 之後可以直接用。
  例：「脈絡訊號圖（就是『你的資料都放在哪』的一張圖）」。
- **白話 ≠ 裝可愛。** 對象是聰明但沒背景的大人，不是小孩。語氣平常，不加表情符號轟炸。

## 三樣東西不准簡化

**數字、來源、人名。** 白話是換說法，不是變模糊。
「大概有點多」❌；「24 筆，全部來自範本頁」✅。

## 換詞表（左邊的詞不准對受訪者說出口）

| 不要說 | 改說 |
|---|---|
| 萃取（判斷） | 把你腦子裡的判斷寫下來 |
| 脈絡 | 你的工作資料／來龍去脈（產品名「脈絡訊號圖」可用，但第一次要加括號解釋） |
| 工作痕跡 | 工作留下的紀錄 |
| 閉環／迴路 | 這件事從頭到尾一圈（圖名可說「哪裡斷掉的圖」） |
| 缺口 | 斷掉的地方 |
| 驗收 | 對答案 |
| 前瞻測試 | 之後拿真實案例對答案 |
| 語料、過擬合、樣本 | 禁用（實測寫進過 HR 的藍圖裡） |
| 觸發條件 | 什麼時候會自己啟動 |
| 調節因子 | 每個人不一樣的地方 |
| 可觀測跡象 | 看得到的訊號 |
| 判斷含量 | 需要動腦的程度 |
| 歸檔（區） | 存進 Notion（的哪裡） |
| 入隊 | 開通權限 |
| 盤點 | 看一遍／清一遍 |
| 產出、交付物 | 做好的東西 |
| 收斂 | 合併成一條 |
| 迭代 | 改一版 |
| 賦能、閉環思維、抓手 | 禁用 |
| 升級偵測 | 「提醒沒用的時候通知你」的功能 |

表以外的詞用新人測試自己判：**要先解釋才懂的，就不要裸講。**

## 圖上的字

- 圖名講圖回答的問題：「哪裡斷掉」勝過「閉環缺口圖」。
- 軸與標籤全部走換詞表。「判斷含量」在圖上寫「需要動腦的程度」。
- 一張圖配一句人話結論，放圖的正下方：「只有一格在動，其他都在等你。」

## 費曼檢查（對自己）

寫完一段如果發現只能用術語講——**那不是對方的問題，是你還沒想清楚。**
回去把事情想到能用生活比喻講出來為止，再開口。
